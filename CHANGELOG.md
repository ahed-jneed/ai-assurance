# Changelog

All notable changes to this repository, newest first within each group. The first version is `0.1.0`, the first public preview. Its section covers everything from the initial commit `74c6463` (5 Nov 2026) up to that version: the November 2026 roadmap cycle ([ROADMAP.md](ROADMAP.md)), the release-candidate verification, and the preparation of the public preview. Each entry is one merged pull request, with the issues it closed; dates are merge dates (UTC). Decisions taken along the way are in the [decision log](docs/product/decisions.md), and what the code now does is in the [capability matrix](docs/capabilities.md).

## 0.1.0 (date to be set when v0.1.0 is tagged)

> **Note for the owner:** `v0.1.0` is not tagged yet. When you tag it, replace "date to be set when v0.1.0 is tagged" in the heading above with the release date (UTC, for example `2026-11-20`), and delete this note.

Highlights:

- **Correctness and security (M1):** an identity adapter that denies by default; access lifecycle and practice administration; plan hashes that bind executed work; rule pack 2026.11.2 with the 2 Dec 2026 milestones; classification v2; report model v2 with ISAE 3000 conclusion types; statistics in which intervals and exact tests decide outcomes, in the engine and the hosted runner alike; an acceptance and independence gate; the Engagement Quality Reviewer role; wrapped dossier signing keys; the Art 4a gate and client-local jobs for special-category data.
- **Multi-framework and GenAI evidence (M2):** criteria as data with typed crosswalks and coverage views; pack #2 (EN 18286 + ISO/IEC 42001, as drafts); NIST AI RMF and AI 600-1 crosswalks; the NYC Local Law 144 bias audit; GenAI evaluation evidence ingested, recomputed and gated in the workspace.
- **Release readiness (M3):** the Playwright persona suite with axe checks; attestation dialogs and permission-aware actions; WCAG AA fixes and a client portal shell; the paged audit trail and practice Access log; the large screens and barrels split into modules.
- **Release verification (15 Nov 2026):** the dead-code sweep ([#37](https://github.com/ahed-jneed/ai-assurance/issues/37)), the fixes from nine rounds of release-candidate verification ([#199](https://github.com/ahed-jneed/ai-assurance/issues/199), [#201](https://github.com/ahed-jneed/ai-assurance/issues/201) to [#204](https://github.com/ahed-jneed/ai-assurance/issues/204), and [#209](https://github.com/ahed-jneed/ai-assurance/issues/209) to [#248](https://github.com/ahed-jneed/ai-assurance/issues/248)) and the documentation refresh ([#38](https://github.com/ahed-jneed/ai-assurance/issues/38)). Nothing from the cycle is open any more: milestones M0 to M3 are closed.
- **Public preview (15 to 19 Nov 2026):** self-hosting with one command and built-in accounts; the ChatGPT sign-in and the Sites hosting integration removed; licence and community files; four self-hosting guides (HTTPS with Caddy, backup and restore, upgrading, configuration); a Docker image that is tested before it is published, and a compose file that runs the published image.
- **Know before you use it:** the self-hosted runtime is a preview. It starts the app with `wrangler dev --local`, Cloudflare's local development runtime, not a production-hardened server. No independent security assessment has been done ([SECURITY.md](SECURITY.md)). The legal content is pending qualified legal review ([#261](https://github.com/ahed-jneed/ai-assurance/issues/261)).

### Public release preparation (15 to 18 Nov 2026)

These changes came in two pull requests. [PR #238](https://github.com/ahed-jneed/ai-assurance/pull/238), 2026-11-15: licence and community files, sanitisation, the first dependency patches and the baseline security headers. [PR #260](https://github.com/ahed-jneed/ai-assurance/pull/260), 2026-11-18: self-hosting, built-in accounts, the removal of the ChatGPT sign-in and the Sites integration, the remaining dependency upgrades, the clickjacking headers and the engine hardening.

- **breaking:** the ChatGPT sign-in and the whole Sites hosting integration are removed (decision D-49). `IDENTITY_MODE=sites` is no longer recognised. The development persona sign-in moves to `/auth/sign-in` and the loopback identity headers to `x-assurance-user-*`. The external worker no longer sends a Sites platform credential (`ASSURANCE_SITE_SERVICE_TOKEN` is gone).
- **feature:** self-hosting with one command (`docker compose up` or `npm run self-host`) and built-in accounts as the default sign-in: owner setup on first visit, invitation sign-up links, PBKDF2 passwords with lockout, `reset-password` (decision D-50). A Docker image is built on pull requests and published to ghcr.io from `main` (changed by PR #280 above: the image is now tested before it is published).
- **security:** React 19.2.9 and Next.js 16.4.6 for published remote-code-execution advisories; zod 4 and current dev tooling; security headers on every Worker response, including `X-Frame-Options: DENY` and `frame-ancestors 'none'`.
- **security (engine):** an encoding-aware PMML DTD guard, a zip entry-count check before the central directory is parsed, the native scorer started in isolated mode, the compute base image pinned by digest and the optional requirements hash-locked.
- **docs:** Apache-2.0 licence, `SECURITY.md`, `CONTRIBUTING.md`, code of conduct, issue templates, Dependabot and a not-legal-advice disclaimer.
